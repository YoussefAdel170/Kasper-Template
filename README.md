## 🚀 Usage

1. **Clone the repository**

   ```bash
   git clone https://github.com/YoussefAdel170/Kasper-Template.git

   ```

2. **Navigate into the project directory**
   ```bash
   cd Kasper-Template
   ```
3. Open **index.html** in your browser.
